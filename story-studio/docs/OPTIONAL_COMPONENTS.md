# PRISM Story Studio 组件关系

| 组件 | 安装方式 | 用途 | 客户端识别方式 |
| --- | --- | --- | --- |
| PRISM H3 | 必装，独立安装 | 视频生成、RTX 视频超分 | 常用安装目录自动发现；也可在设置中定位控制台 |
| FFmpeg / FFprobe | 客户端内置 | 剪辑、合成、媒体校验 | 随安装包提供并自动启用 |
| Real-ESRGAN | 客户端内置 | 图片 2 倍或 4 倍超分 | 随安装包提供并自动启用 |
| ACE-Step 1.5 | 可选，独立离线安装 | 本机配乐生成 | 安装器注册本机发现信息；也兼容常用目录扫描和手动定位安装目录 |

ACE-Step 1.5 的有效安装应包含：

```text
ACE-Step-1.5\
  .venv\Scripts\python.exe
  runtime\python\python.exe
  checkpoints\
```

ACE 安装器会重写虚拟环境的 Python Home，因此安装目录可以由用户选择，不依赖打包电脑的旧路径。客户端只记录并复用独立组件路径，不移动模型目录。组件状态只证明程序与必要模型文件已发现；真实生成仍应按任务分别验收输出文件、媒体可解码性、参数与最终内容。
