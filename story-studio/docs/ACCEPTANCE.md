# 第一版验收标准

## 固定样例

开工前由项目方提供一段可合法用于测试的小说片段，覆盖至少两集，并确认目标题材、时长、比例、语言和画风。

## 功能验收

- 小说能够拆成有起承转合和集尾钩子的单集计划。
- 用户可以逐集修改、批准并继续生产。
- 已审批剧本能够自动提取完整人物介绍；所有必需角色恰好覆盖一次，人物事实带有可核对的剧本逐字证据。
- 原文已知外貌/服装与待设计内容分开保存，不把模型补充设定标成原文事实。
- AI可以推荐画风，但只有用户选择并批准的画风版本能够解锁人物图片生成。
- 人物资产板提示词只能基于已批准人物介绍和已批准画风生成，并且必须按已批准人物顺序完整唯一覆盖。
- 程序编译后的每份人物主资产提示词只包含一次`基础设定`、`氛围、画质与摄影风格`、`画面内容与布局`、`摄影机与成像`和`负面词`，固定横版3:2“左面部近景 + 右完整全身”双栏布局不由模型改写，首张图不混入三视图，生产提示词不得包含外部产品、平台或品牌来源表达。
- 主资产不得固化雨湿、泥渍、中毒、血迹、战损等临时剧情状态；代表性道具只能由已批准人物事实支持，且只出现在主全身图。
- 画布上的“生成详细三视图”按钮只在人物主资产按精确版本批准、且当前Images Provider已验证参考图生成能力时可用；点击只生成一份绑定主资产版本的正面/严格左侧面/完整背面派生资产，不自动连续重试。
- 详细三视图提示词由程序固定编译，不调用文字API；完整提示词只包含一次`基础设定`、`氛围、画质与摄影风格`、`画面内容与布局`、`摄影机与成像`和`负面词`，只使用一张已批准主资产图作为参考，并记录该主资产的精确版本。
- 每个人物设计至少包含三条可重复身份锚点和一条自然不对称特征，负面词保留当前任务最高风险的5至8项。
- 场景视觉提案必须将所有剧本场次按顺序完整唯一覆盖；同一物理地点不得因人物动作、镜头目的或破坏前后状态而重复建立场景资产。
- 每个场景主资产必须区分剧本逐字事实与待审批设计决定，包含稳定空间布局、材质、光色、天气、可复用镜头覆盖和至少三处固定地标；后续毁坏状态必须单独绑定场次与逐字证据。
- 场景事实与状态变体引用的证据必须来自程序生成的对应场次证据目录；不存在、跨场或无法回填为剧本逐字原文的证据ID必须拒绝整个草稿。
- 场景主资产提示词固定为横版16:9纯环境空镜，不混入人物、剧情道具或后续毁坏状态；只有视觉提案与提示词集合按精确版本批准后才允许生图。
- 已批准场景主资产必须进入独立多视角阶段；派生视角使用主场景图作为参考，并绑定其精确ID、版本和文件哈希。固定地标、相对空间关系、道路轴线、天气和画风漂移时不得通过。
- Images Provider参考图能力未验证时，场景多视角按钮必须禁用并说明原因；不得用无参考文生图冒充基于主场景的派生视角。
- 剧本中的同一道具即使使用多个称谓，也必须归并为一个稳定道具ID；每个称谓和状态事实均可追溯到对应场次证据。
- 道具主资产提示词固定为横版3:2五视图资产板，同一件道具的三分之四、正面、侧面、顶面和底面在轮廓、比例、材质及细节锚点上必须一致。
- 道具基础主资产不得混入人物、手、剧情环境或激活、雷击、碎裂等临时状态；状态变体须独立记录并在基础提示词精确版本获批后另行生成。
- 分镜文字默认按15秒分段，且分段时长可配置；程序沿整集时间轴建立固定槽位，除整集最后不足所选时长的余数段外，每段必须与用户选择完全一致。总导演按剧情密度把完整场次顺序分配到槽位，每段只属于一个场景，场尾转场只发生在分段边界；第1集105秒在默认配置下应得到7个15秒分段。
- 每张分镜卡片只需简洁说明地点、人物、核心动作、关键逐字对白、画面重点和基本机位；不得强制文字模型在同一阶段重复输出逐段五段式长生图提示词。
- 文字模型不得复制或选择长资产ID；只返回人物名、场景视角和道具状态语义，由程序自动绑定对应的已批准精确资产版本。任何语义找不到唯一批准资产时必须阻断，不得静默替换。
- 故事板默认六宫格并允许不生成、单图、四宫格、六宫格或九宫格；所选画格必须按固定阅读顺序连续覆盖当前分镜时长。隐藏生图提示词可在图片详情查看，不增加强制审核步骤。
- 宫格是时间检查点而非固定切镜数。每格必须包含镜头组、与前格关系、切镜触发器、起止状态、行动单元、动作主体、动作摘要和阶段；相邻状态必须精确相接，同一行动不得重复完成，新增镜头组必须有具体切镜原因，4至6秒分段最多两个镜头组。
- 宫格故事板的文字Agent必须基于剧本证据、人物/场景/道具资料和相邻分镜，输出本段人物、状态、场景、道具与排除元素的语义判断，并使逐格规划和最终隐藏提示词与该判断一致；本地程序不得自行推断剧情允许或禁止元素。
- 本地门禁只负责确定性验收：输出Schema、所选格数、0至分镜时长的连续覆盖、批准资产存在性和版本；生成图片的实际内容仍由用户审核，未来视觉模型只能作为可选辅助。
- 后台仍须保证剧本动作和对白完整唯一覆盖、对白顺序及说话者正确、批准资产引用有效、道具状态因果正确、场尾转场一致。
- 视频提示词的结构化时间段必须按顺序覆盖所有画格；不得跨越镜头组边界合并时间段，必须继承首尾状态、行动单元、切镜关系和原因，并在执行正文中明确动作主体。缺少新版导演连续性字段的旧六宫格不得直接生成新版视频提示词。
- 普通动作证据顺序、重复或轻微覆盖差异不得导致整个分镜任务只能由开发者修复；程序应先排序去重并以审核警告展示。JSON损坏、时长错误、对白改写、资产不存在或道具因果错误仍必须阻断。
- 角色、场景、道具均有稳定ID、版本、提示词和参考图。
- 每个镜头能够查看、修改提示词和参考资产。
- 修改上游后能够明确标记受影响的下游资产。
- 可以分别运行单镜头和整集自动任务。
- 选择“续接上一段”时，即使前段仍在生成，也能先保存为等待依赖的本地任务；界面不得误报生成失败或提前向H3提交。前段成功返回可续接结果后按已保存参数提交一次；前段失败时暂停等待且不自动重试，等待任务可以取消并在刷新后保持状态。
- 所有镜头视频可以与BGM合成为最终MP4。

## 媒体验收

每个输出依次验证：

1. 任务状态完成。
2. 文件存在且大小合理。
3. FFprobe可读取。
4. 分辨率、时长、帧率和音轨符合记录。
5. 视频可解码并可播放。
6. 镜头数量完整、顺序正确。
7. 最终成片包含预期BGM及字幕策略。

## 质量验收

质量通过固定样片人工评审，不使用“模型返回成功”代替：

- 主要角色身份和服装连续性。
- 场景空间、时间和画风连续性。
- 道具归属和位置合理。
- 动作与镜头提示词基本一致。
- 镜头节奏、集尾钩子和总时长符合项目目标。
