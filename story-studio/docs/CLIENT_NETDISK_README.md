# PRISM Story Studio 0.1.35 安装说明

## 安装顺序

1. 安装与本机显存档位匹配的 PRISM H3。PRISM H3 是视频生成后端，也提供 RTX 视频超分能力。
2. 运行 `PRISM-Story-Studio-Setup-0.1.35.exe`，选择安装位置。安装器会自动创建程序目录，完成空间预检、文件安装和内置组件校验。
3. 如需本机生成配乐，再运行 ACE 独立包中的 `PRISM-ACE-Step-1.5-Setup.exe`；不使用本机配乐时可以跳过。

FFmpeg、FFprobe 与 Real-ESRGAN 图片超分已经包含在客户端中，无需额外安装。

## 首次启动

1. 打开右上角“设置”。
2. 在“系统与诊断”检查组件状态：
   - PRISM H3：客户端会从常用安装位置和 Windows 安装记录中自动发现；点击“启动并连接”后会等待 H3 与视频后端就绪。
   - 媒体处理组件：应显示可用。
   - 图片超分：应显示可用。
   - ACE-Step 1.5：安装后显示可用，未安装时显示可选。
3. 如果客户端没有自动找到 H3，点击“定位H3”，选择 `PRISM H3 控制台.exe`。选择后立即启用并自动连接。
4. ACE 安装器会写入本机发现信息；如果客户端仍未自动找到，点击“定位ACE”并选择 ACE-Step 1.5 安装目录。
5. 在“文件与存储”确认项目库位置；项目、素材与成片默认保存在用户视频目录下的 `PRISM Story Studio` 文件夹。
6. 按需填写 API 连接。API Key 使用 Windows 安全存储加密保存。

文字 Agent 支持 OpenAI Responses、OpenAI Chat Completions 和 Anthropic Messages 三类协议。OpenAI、DeepSeek、Kimi、智谱 GLM 和 Claude 官方预设会自动选择对应协议。Responses 请求使用流式接收，后台持续读取并在完成和校验通过后显示正式结果；智能拆集单次请求等待上限为 300 秒。断流后保留诊断，由用户决定是否重新提交。模型检测会核对有效模型信息，实际生成权限以真实任务为准。视频提示词在同一次生成中完成自检，必要的后续修改由用户发起。

## 0.1.35 更新说明

推荐标题支持完整短语与自然换行。人物档案使用当前剧本提取候选，并按原文编号绑定依据。创作阶段统一精简提示：普通建议折叠查看，引用措辞与索引诊断留在内部，影响制作的实际问题明确显示。

自由画布支持按字段撤销、多选复制与排版、连线用途及稳定重接。撤销按项目隔离，恢复连线原顺序，输入面板同步撤销内容；生成中的节点和项目切换受保护，结果返回后恢复正常操作。

视频提示词明确区分图片标签、人物标签与故事板画格编号；生成结果和 H3 提交前检查正文引用。引用缺失或格式错误时提示具体位置并保留原稿，标签清理保留待修正信息。


图片请求失败时分别报告生成等待超时、响应读取中断和结果下载失败，并保留等待时长、等待上限、连接代码与可用的请求编号。等待超时后，请先到服务商后台核对请求是否已经完成，再决定是否重新提交。角色图片重生成失败时保留已有图片，并明确提示本次请求失败。

包含以下功能：

图片生成统一使用保存的 1—4 路并发额度，角色、场景、道具、故事板与自由画布共享调度。面板显示当前生效额度、图片执行数与排队数，并提示未保存的修改。剧本阅读及其他滚动区域采用深色滚动条。

测试连接时，裸域名的模型查询不可用会自动检查同域名 /v1，检测成功后保存有效地址。鉴权或限流错误保留原始状态；模型查询与实际生成权限分别验证。

以下功能随版本保留：

视频提示词生成和单段修复会把当前整张宫格图片交给文字 Agent 阅读，按实际构图、人物位置、动作状态与镜头顺序编写正文。文字服务需要支持图片输入。H3 全能参考同时接收整张宫格与本段必要的角色、场景、道具图，并标明画格与时间段的对应关系。

旧项目保留现有正文，兼容原有资产编号；要让旧正文重新对齐实际图片，可打开该段视频提示词并点击“让 Agent 修复本段”，检查后保存确认。更换故事板只标记对应段需要更新，已有视频保留。图片读取或接口请求失败会显示错误，由用户决定下一步。

此版本包含以下 0.1.29 修复：

导演模式与自由画布统一按用户选择的参数提交 H3，取消显存估算的确认拦截。视频提示词可以单独保存确认；对仍有校验问题的可读草稿，可以选择“采用当前草稿，跳过本次校验”。选择“暂留问题段”可先确认并制作其余已完成段，待处理分段与已有结果继续保留。

单段修复使用当前编辑正文，兼容旧项目缺少内部草稿字段的情况。保存确认只更新项目；点击修复或生成按钮才会发起相应请求。此版本包含 0.1.28 的结构化请求修复。

## 安装包校验

安装前可使用 PowerShell 校验文件：

```powershell
Get-FileHash .\PRISM-Story-Studio-Setup-0.1.35.exe -Algorithm SHA256
```

将结果与同目录 `SHA256SUMS.txt` 对照。

Studio 安装成功后会在程序目录写入 `安装结果.txt`。应用启动问题会在设置页显示日志目录，安装阶段的空间不足或内置组件缺失会由安装器直接说明原因。

## Windows 安全提示

当前 0.1.35 安装包为未签名的内部发行版。Windows 可能显示 SmartScreen 提示；请先核对 SHA-256，并确认文件来自可信的 PRISM 网盘目录。

第三方组件来源与许可证见 `CLIENT_THIRD_PARTY_NOTICES.md`，同一份说明也会安装到客户端资源目录。
