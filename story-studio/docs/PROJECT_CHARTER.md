# 项目章程

## 目标

在一台高显存本地工作站上，完成从小说片段到分集短剧成片的可审核自动化流程。首轮以一套代表性样片跑通为验收核心，不建设社区、积分、模型商城或公共SaaS能力。

## 第一版范围

1. 小说导入、章节预切分和语义拆集。
2. 单集剧本生成、修改和确认。
3. 从已审批剧本自动提取人物介绍，保留剧本证据并由用户审核。
4. AI可提供画风候选，但由用户选择并锁定全片统一画风。
5. 角色形象、场景主资产、场景多视角和道具资产生成与版本管理；人物形象不得早于人物介绍和画风审批；单张场景主图可用后即可直接生成该场景多视角，不等待整组场景确认。
6. 分镜提示词、候选图、九宫格和单图修改。
7. 视频提示词、参考资产绑定和 PRISM H3 BF16 任务。
8. 逐阶段审批和全自动运行两种执行模式。
9. MiniMax Music 3 配乐与最终合成。
10. 项目保存、失败恢复、结果下载和基础日志。

## 明确不在第一版

- 社区和公开发布平台。
- 积分、会员、计费和模型商城。
- 多租户、多人同时生成和公网开放API。
- 自动承诺所有小说题材都能一次生成合格成片。
- 自动删除旧版本或失败产物。

## 技术原则

- GPT 类任务、图片、视频、音乐分别通过独立 Provider 接口接入。
- PRISM H3 保持独立仓库和独立进程。
- 数据契约优先于UI；所有生成结果都可追溯到输入、参数、资产版本和任务ID。
- 审批模式默认启用；全自动模式必须显式选择。
