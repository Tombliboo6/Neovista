# PRISM AutoDrama 协作规则

## 项目边界

- 本仓库负责编排、资产、审批、提示词、任务状态和最终合成。
- PRISM H3 是独立视频后端，通过适配器调用；不得把 `E:\ChatGPT\minimax` 的未提交源码直接复制进来。
- 所有外部模型必须通过 `src/providers/` 接口接入，领域层不得直接调用 SDK 或 HTTP。

## 开发规则

- 修改前先读取 `.ai-pm/PROJECT_STATE.md`、`docs/PROJECT_CHARTER.md` 和相关接口文档。
- 剧本、资产、镜头和生成任务必须保留稳定 ID、版本和审批状态。
- 修改上游只标记下游 `stale`，不得自动删除已生成资产。
- 失败后不得静默更换参数或无限重试；保留错误、参数和已有结果。
- 逐阶段审批模式下，未经用户确认不得继续产生付费 API 调用或启动下一阶段。
- API Key、客户原文、客户素材、生成媒体和模型文件不得进入 Git。

## 验收原则

依次区分：任务返回、文件存在、媒体可解码、参数正确、镜头完整、音轨完整、最终成片可播放。只有最后一层通过才可标记整片完成。
